# PoE Companion 설치본과 안내 / Installers and guides

Path of Exile 1과 Path of Exile 2를 위한 음성 동료 앱의 설치본을 여기서 받습니다. 코드는 비공개이고, 이 저장소에는 설치 파일과 안내 문서만 있습니다.

This repository holds the Windows installers and the guides for the voice companion apps for Path of Exile 1 and Path of Exile 2. The source code is private; only releases and documents live here.

## 받기 / Download

- 최신 설치본 / latest release: https://github.com/ernestolee13/poe-companion-releases/releases/latest
- PoE1 Companion: `PoE1 Companion Setup <version>.exe`
- PoE2 Companion: `PoE2 Companion Setup <version>.exe`

두 앱은 나란히 설치할 수 있고 설정과 기록이 섞이지 않습니다. 설치 때 관리자 권한을 묻습니다(카카오 클라이언트와 같은 권한이 필요합니다).

Both apps install side by side and keep separate settings and history. The installer asks for administrator rights, because the Kakao client runs at that level.
