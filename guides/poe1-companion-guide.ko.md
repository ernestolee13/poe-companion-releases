# PoE1 Companion 활용 가이드

설치부터 캐릭터 꾸미기, 문제 해결까지 순서대로 적었습니다. 0.1.66 화면을 기준으로 고쳤습니다. 글보다 화면이 편하면 [화면으로 보는 설정 안내](poe1-companion-setup-visual.ko.md)를 먼저 보세요. 외부 서비스의 요금과 한도는 2026-11-09에 확인한 값입니다. 앱이 무엇을 하는지는 소개서(poe1-companion-intro.ko.md)에 있습니다.

## 1. 설치와 첫 설정

1. 최신 설치 파일 `PoE1 Companion Setup <버전>.exe`을 실행합니다 (https://github.com/ernestolee13/poe-companion-releases/releases/latest). 관리자 권한을 묻습니다. 카카오 클라이언트와 같은 권한이 필요해서입니다.
2. PoE1 Companion은 처음부터 PoE1 전용으로 켜집니다. 게임을 따로 고를 필요가 없습니다.
3. 게임 로그 경로를 확인합니다. 앱이 먼저 찾아 보여 주고, 못 찾으면 직접 고릅니다. "자동 찾기" 버튼도 있습니다.
   - 스팀: `Steam\steamapps\common\Path of Exile\logs\Client.txt`
   - 독립형: `Grinding Gear Games\Path of Exile\logs\Client.txt`
   - 카카오: `Daum Games\Path of Exile\logs\` 아래 `KakaoClient.txt` 또는 `Client.txt`
4. 리그를 고릅니다. 새 리그가 열리면 목록을 새로 고치세요. 리그 이름은 거래소에서 그때 받아 옵니다.
5. 설정 > 모듈 > 두뇌(대화)에서 프리셋(groq, gemini, openrouter, openai, deepseek, anthropic, ollama, lm-studio 중 하나)을 고르고 키를 붙여 넣습니다. 연결 테스트를 눌러 확인합니다.
6. 저장하고 설정 창 위쪽의 "시작하기" 버튼을 누릅니다. 멈출 때는 같은 자리의 "멈추기"를 누릅니다. 설정 > 시스템 > 시작 방식에서 "앱을 켜면 자동으로 시작"을 켜 두면 누르지 않아도 됩니다.
7. 게임을 켭니다. 지역에 들어가거나 레벨이 오르면 동료가 반응합니다.

게임은 창 모드나 테두리 없는 창 모드여야 합니다.

게임 옵션 UI에서 "모든 대화를 채팅에 출력"을 켜 두면 동료가 맵 안에서 만난 리그 콘텐츠(아인하르, 알바, 심연 같은 것)를 NPC 대사로 알아차립니다. 대사 내용은 저장하지 않고 어떤 콘텐츠였는지만 기억합니다. 꺼 두면 그 기능만 빠지고 나머지는 그대로입니다.

첫 실행 때 "시작하기" 체크리스트가 뜹니다. 설정 > 캐릭터 탭 맨 위에도 같은 목록이 있습니다. 두뇌 키, 게임 로그 연결, (선택) 내 캐릭터 정보, (선택) 음성과 청각 확인, 감정 단축키 확인 순서입니다.

### 설정 창 둘러보기

- 탭은 캐릭터, 모듈, 도구, 게임, 시스템 다섯 개입니다. 왼쪽 메뉴에서 탭을 고르면 그 아래에 탭 안의 항목이 나열되고, 누르면 그 자리로 갑니다.
- 맨 위 상태 줄에는 두뇌, 음성, 청각, 검색, 비전, 게임로그, 거래소가 점과 이름으로 보입니다. 점 색으로 상태를 알 수 있고, 마우스를 올리면 자세한 내용이 나옵니다.
- 자주 안 만지는 칸은 "고급 설정" 안에 접혀 있습니다. 눌러서 펼칩니다.
- 기억, 내가 알고 있는 너, 플레이어 노트, 우리 기록은 한 줄 요약만 보이고 "자세히 보기"를 누르면 창으로 열립니다.
- 게임 탭은 게임 로그, 내 캐릭터, 빌드 계산 엔진(PoB), 거래소(로그인, 서버, 빠른 검색 패널), 아이템 감정 순서입니다.
- 설정 사이에 "관련 설정:" 링크가 있으면 다른 탭의 이어지는 칸으로 바로 갑니다.

### 모듈별 역할: 하나씩 넣으면 무엇이 좋아지나

두뇌 키 하나만 있어도 앱은 돌아갑니다. 나머지는 빼도 동작하고, 넣을 때마다 그 부분이 좋아집니다. 대부분 무료 키로 됩니다.

| 모듈 | 하는 일 | 없으면 | 무료로 채우는 법 |
|---|---|---|---|
| 두뇌 (필수) | 대화와 판단 전체 | 앱이 대답을 못 함 | Gemini 또는 Groq 무료 키 (아래) |
| 목소리 | 대답을 소리로 읽기 | 기본 edge 목소리(무료, 키 없음)라 기계음이 셈 | Fish Audio 무료 키 (아래). 체험 코드는 한국어 12개 중 고르기 |
| 청각 | 내 말을 글로 바꾸기 | 타자로만 대화 | 기본이 이 PC 안 로컬 인식이라 키 없이 무료. 첫 사용 때 모델을 한 번 내려받음 |
| 웹 검색 | 빌드 유행, 패치 소식 같은 최신 정보 찾기 | 게임 기록과 시세로만 답하고 최신 소식은 모른다고 함 | Tavily 무료 키, 매달 1,000번 (아래) |
| 비전 | 붙여 넣은 스크린샷 읽기 | 사진을 보여 줘도 못 봄 | 두뇌와 같은 키에 이미지를 받는 모델 이름만 적기 (예: Gemini flash-lite) |
| Jev (빠른 판단) | 대답할지, 짧게 받을지, 넘어갈지 0.5초 안에 고르기. 빌드 사이트에서 길 찾기 | 모든 말에 길게 답하고, 사이트 길 찾기를 두뇌가 느리게 대신 | 두뇌를 OpenRouter 키로 쓰면 자동으로 켜짐(판단 한 번에 0.0002달러 안팎이라 소액 크레딧 필요). 체험 코드에는 들어 있음 |
| 대답 전 추임새 | 대답을 만드는 1초 동안 할 짧은 추임새 고르기 | 준비된 추임새 중 무작위 | OpenAI 호환 키 아무거나 |

### 무료 키 받는 곳 (2026-11-09 확인)

- Groq: 카드 없이 가입합니다(console.groq.com/keys). 앱 기본 모델 openai/gpt-oss-20b의 무료 한도는 분당 30회, 하루 1,000회입니다(2026-11-11). Llama 3.1 8B는 유료 전용으로 바뀌어 모델 칸에 적으면 안 됩니다.
- Google AI Studio: 카드 없이 키를 받습니다(aistudio.google.com/apikey). 앱 기본 모델 gemini-3.5-flash-lite의 무료 한도는 분당 15회, 하루 500회이고 2.5 계열은 신규 계정에 막혀 있습니다(2026-11-11). 무료 등급 입력은 구글 제품 개선에 쓰일 수 있습니다.
- OpenRouter: ":free"가 붙은 모델 이름을 모델 칸에 직접 적습니다. 분당 20회, 하루 50회입니다. 크레딧 10 이상을 한 번 사면 하루 1,000회가 됩니다.
- GCP 300달러 체험: 쓸 수 없습니다. 구글 공식 안내에 300달러 크레딧은 AI Studio의 Gemini API 비용에 쓸 수 없다고 적혀 있고, Vertex AI도 2026-11-16 이후 가입자는 제외됩니다(2026-11-11 확인).

모델 칸을 비우면 프리셋 추천 모델을 씁니다.

### 웹 검색: Tavily 무료 키 (2026-11-14 확인)

빌드 유행이나 패치 소식처럼 앱에 없는 최신 정보를 물으면 웹에서 찾아와 답합니다. 키가 없으면 설정 위쪽 상태 줄의 "검색"이 꺼진 표시로 뜨고, 게임 기록과 시세로만 답합니다. 빌드 가이드를 찾아 주는 것도 이 키로 합니다. 체험 코드에는 웹 검색이 들어 있지 않습니다.

1. tavily.com 에서 가입합니다. 카드 없이 매달 1,000크레딧을 줍니다. 일반 검색 한 번이 1크레딧이라 혼자 쓰기엔 충분합니다.
2. 대시보드의 API 키(tvly-로 시작)를 복사합니다.
3. 설정 > 모듈 > 검색에서 "웹 검색 사용"을 켜고, 프리셋을 tavily로 두고, API 키 칸에 붙여 넣은 뒤 저장합니다.

### 설정이 귀찮다면: 체험 코드

키 받는 과정이 번거로우면 help@vibestash.app 로 "체험 코드 요청"이라고 메일을 보내 주세요. 두뇌, 목소리, 음성 인식까지 한 번에 되는 묶음 코드를 드립니다. 한 코드에 10달러에서 20달러어치가 들어 있어 몇 주는 설정 없이 써 볼 수 있습니다. 수량이 한정돼 있어 한 사람에 하나입니다. 받은 코드는 설정 > 모듈 > 두뇌에서 "체험 게이트웨이"를 고르고 키 칸에 붙여 넣으면 됩니다.

### 목소리: Fish Audio 무료 모델로 바꾸기

키 없이 두면 edge-local 목소리가 나오는데 기계음이 셉니다. fish.audio 에 가입하고(카드 없음) 계정 메뉴의 API Keys에서 키를 만든 뒤, 설정 > 모듈 > 음성(TTS)에서 프로바이더를 "Fish Audio"로 고르고 API 키 칸에 붙여 넣고 연결 테스트, 저장합니다. 모델과 보이스 칸은 비워 두면 s2.1-pro-free와 추천 목소리를 씁니다. 체험 코드를 쓰는 중이면 건드리지 않아도 됩니다. Fish 무료 제공은 2026-11-30까지로 안내돼 있고 끝나면 앱이 edge-local로 스스로 돌아갑니다.

### 대답 전 추임새는 무엇인가

모듈 탭 아래쪽 "대답 전 추임새"는 동반자가 답을 만드는 1초 남짓 동안 먼저 말하는 짧은 추임새를 고르는 작은 모델입니다. 예전 이름은 "판단 (선응답)"입니다. "대답 전 추임새를 모델이 고르기"를 켜 두고 "고급 설정"의 API 키(OpenAI 호환) 칸에 키를 넣으면 상황에 맞는 추임새를 고르고, 비워 두면 준비된 추임새 중 하나를 무작위로 씁니다. 대답 자체는 같습니다. 처음에는 비워 두고 넘어가도 됩니다.

## 2. 말하는 법

마이크 방식은 설정 > 모듈 > 청각(STT)에서 고릅니다.

- 상시 듣기(기본): 말이 끝날 때마다 알아서 보냅니다.
- 푸시투토크: 마이크 버튼을 누르는 동안만 듣습니다.
- 말하기 키(기본 백틱 키): 누르고 있는 동안 듣고, 떼면 보냅니다. 설정 > 시스템 > 단축키의 말하기 키 방식을 "한 번 누르면 시작, 다시 누르면 보내기"로 바꾸면 한 번 눌러 듣기 시작, 다시 눌러 보냅니다. 이때는 30초가 지나면 자동으로 보냅니다.

조용한 환경이 좋습니다. 동반자가 말하는 동안에는 에코 캔슬이 켜진 마이크에서만 듣습니다. 마이크가 없으면 글로 물어도 됩니다.

### 이런 말을 해 보세요

- 시세: "디바인 몇 카오스야?", "이 아이템 얼마야?"
- 지금 상황: "여기 어디야?", "방금 왜 죽었지?" (죽은 이유가 기록에 없으면 단정하지 않습니다)
- 빌드: "이 PoB 링크 읽어 줘", "내 빌드 약한 데가 어디야?", "내 저항 몇이야?"
- 참고 빌드: "이거 '게이머비누 정전기'로 참고 빌드 등록해줘 (링크)", "게이머비누 정전기랑 비교해 줘"
- 장비: "10디브로 저항 맞추게 업그레이드 계획 짜줘", "목걸이만 5디브로 찾아 줘"
- 정보: "이번 패치노트에서 바뀐 거 찾아 줘", "이 보스 공략 알려 줘"
- 파밍: "지금 카오스 벌기 좋은 방법 뭐야?"

모르는 것은 모른다고 합니다. 3.30 새 메커닉은 패치노트가 나와야 알 수 있고, 동료가 "패치노트 확인해 봐"라고 하는 것이 그 뜻입니다.

조회가 오래 걸리면 1분쯤에서 왜 멈췄는지 한 줄로 말하고 끝냅니다. 이미 소리 내 말하고 있는 대답은 끊지 않습니다. 잠시 뒤 다시 물어보거나 질문을 좁혀 보세요.

## 3. 단축키

설정 > 시스템 > 단축키에서 바꿉니다. 입력란을 누르고 조합을 누르고, Esc로 취소합니다. 보통 Ctrl, Alt, Shift 중 하나를 함께 눌러야 합니다.

| 기능 | 기본값 |
| --- | --- |
| 빠른 감정 (빠른 시세 패널) | Ctrl+D |
| 상세 감정 | Ctrl+Alt+D |
| 말하기 키 | 백틱 키 (누르는 동안 듣기) |
| 화면 공유(지금 화면을 동반자에게 보여 줌) | PrintScreen (게임이 앞에 있을 때) |
| 피드 오버레이 열기와 닫기 | 설정에서 지정 |
| 음소거 켜기와 끄기 | 설정에서 지정 |
| 참고 이미지 1번부터 5번 보이기와 숨기기 | 설정에서 지정 |

감정 단축키는 아이템에 마우스를 올리고 누릅니다. 앱이 Ctrl+C를 대신 눌러 복사하고, 끝나면 원래 클립보드를 되돌립니다. "게임 창이 앞에 있을 때만" 옵션을 켜 두면 게임이 아닌 앱에는 키를 보내지 않습니다. 나머지 단축키는 화면만 바꾸고 게임에는 입력을 보내지 않습니다.

PrintScreen은 가로채지 않아서 윈도우 기본 동작도 그대로 됩니다. 단축키가 이미 다른 프로그램에서 쓰이면 앱이 알려 주고 대체 키를 잡습니다.

## 4. 시세와 거래

- Ctrl+D 빠른 검색 패널: 어웨이큰 PoE 트레이드처럼 거래소 검색 패널이 뜹니다. 옵션 줄, 합산, 베이스, 타락, 아이템 레벨, 룬 소켓을 켜고 끄며 다시 검색합니다. 패널이 답하는 동안 동료는 말하지 않습니다. 설정 > 게임 > 거래소의 "빠른 검색 패널 (Ctrl+D)"에서 끌 수 있습니다.
- Ctrl+Alt+D: 같은 아이템의 상세 분석입니다. 지도면 위험 옵션을 읽고 돌릴지, 다시 굴릴지, 건너뛸지 답합니다. 빌드를 알려 둔 상태(PoB 링크)면 그 빌드에 해로운 옵션만 따집니다.
- 창고 검색어: "물리 반사랑 재생 불가 빼고 수량 80 넘는 지도 검색어 만들어 줘"처럼 말하면 검색창에 붙여 넣을 문자열을 돌려줍니다. 직접 복사해서 붙여 넣으세요. 동료는 게임 창에 아무것도 입력하지 않습니다. 검색창 글자 수 제한 때문에 다 못 넣은 옵션은 따로 말해 줍니다.
- 가격은 카오스 기준입니다. 디바인으로만 나오는 물건은 카오스 합계에서 빠집니다.
- 매물의 귓말 버튼은 귓말을 클립보드에 복사합니다. 게임 채팅창에 직접 붙여넣어야 합니다. 앱이 대신 보내지 않습니다.
- 확인하지 못한 가격은 지어내지 않고 못 구했다고 말합니다.
- 거래소가 느리거나 막히면 가격을 못 구하는 날이 있습니다.

### 거래소 로그인

설정 > 게임 > 거래소에서 "거래소 로그인 세션 사용"을 켜고 "로그인"을 누르면 앱 안 브라우저가 열립니다. 카카오 계정이든 글로벌 계정이든 내 계정으로 직접 로그인합니다. 비밀번호는 앱이 보지 않고, 로그인 쿠키만 이 PC에 암호화해 둡니다.

- 한 번 로그인하면 앱을 껐다 켜거나 업데이트해도 로그인이 유지됩니다.
- 거래소가 읽기를 거절하면(로그인이 풀린 경우) 위쪽 상태 줄의 거래소가 "로그인 안 됨"으로 바뀌고 피드에 알림이 한 번 뜹니다. 같은 자리에서 다시 로그인하면 됩니다.
- "내 캐릭터 불러오기"를 누르면 지금 캐릭터를 읽어서 내 PoB 빌드를 자동으로 만듭니다. 장비 옵션까지 넣어서 만들고, 카카오 서버도 됩니다. PoB 링크를 직접 넣어 두면 그쪽이 우선합니다.
- 계정 이름을 못 찾으면 같은 곳의 계정 이름 칸(Name#1234)에 넣어 주세요.

### 장비 업그레이드 계획

예산을 말하면 내 빌드에 모자란 것을 계산해서 부위별로 살 것을 골라 줍니다.

1. "10디브로 저항 맞추게 업그레이드 계획 짜줘"처럼 예산과 목표를 말합니다.
2. PoB 수치로 화염, 냉기, 번개, 카오스 저항과 생명력이 모두 합쳐 얼마나 모자란지 계산합니다. 유니크와 고정해 달라고 말한 부위는 건드리지 않고, 약한 부위부터 예산을 나눕니다.
3. 거래소 검색은 요청이 여러 번 나가 시간이 걸려서, 계획을 먼저 보여 주고 찾아도 되는지 묻습니다. 기다리는 동안 맵 한두 판 돌고 오라고 권합니다.
4. 좋다고 하면 부위마다 고른 매물을 베이스, 주요 옵션, 단위가 붙은 가격, 거래소 링크와 함께 보여 주고, 고른 것을 함께 끼웠을 때를 PoB로 계산합니다. 피드 카드의 "구매" 버튼을 누르면 같은 검색으로 거래소 사이트가 열립니다.

한 부위만 바꾸려면 "목걸이만 5디브로"처럼 말하세요. 계획 단계 없이 바로 찾습니다. 부족분은 내 빌드의 PoB 수치로 계산하니, PoB 링크를 넣어 두거나 거래소 로그인 뒤 내 캐릭터를 불러와 두세요.

### 크래프팅

애매한 레어를 팔지, 한 번 더 손볼지 정할 때 씁니다. 시세 단축키로 아이템을 넣은 뒤 이렇게 물어보세요.

- "여기 엑잘 박으면 저항 붙을 확률 어때?": 빈 접두, 접미 칸을 보고 게임 데이터의 등장 가중치로 확률을 계산합니다. 이미 붙어 있는 저항은 다시 안 붙는다는 것도 알려 줍니다.
- "제작대로 하면?": 제작대에서 확정으로 붙일 수 있는 옵션과 비용(예: 모든 원소 저항 9~12%, 카오스 1개)을 알려 줍니다.
- 가치 비교: 지금 아이템과 옵션이 붙었을 때의 아이템을 같은 조건으로 거래소에서 찾아, 가장 싼 매물 기준으로 값을 매깁니다. 엑잘이나 제작대 비용을 빼서 "그냥 파는 게 나은지, 붙여서 파는 게 나은지"를 숫자로 답합니다. 비슷한 매물이 적어 값이 크게 튀면 추정이 불확실하다고 말합니다.

예시(자수정 반지, 생명력과 화염, 냉기 저항이 붙은 레어): 엑잘로 저항이 붙을 확률은 10.75%이고 기대값이 마이너스라 파는 게 낫다, 제작대로 모든 원소 저항을 붙이면 약 15카오스가 돼서 해볼 만하다, 이런 식으로 답합니다.

- 지금은 엑잘, 리갈, 증강, 카오스, 연금, 에센스, 화석, 제작대 같은 기본 크래프팅을 다룹니다. 수확이나 영향력 전용 옵션은 아직 빠져 있습니다. 새 아이템에 카오스나 연금을 칠 때의 확률은 시뮬레이션이라 대략값입니다.
- 희귀도처럼 접두와 접미 양쪽에 다 있는 옵션은 어느 쪽인지 헷갈릴 수 있어서, 그럴 때는 그렇다고 알려 줍니다. 게임에서 Ctrl+Alt+C로 복사하면 정확히 구분됩니다.

## 5. PoB 빌드

- 설정 > 게임 > 내 캐릭터의 "지금 캐릭터의 PoB 링크" 칸에 공유 링크를 넣으면 지금 캐릭터로 등록합니다. 비워 두고 거래소에 로그인해 "내 캐릭터 불러오기"를 누르면 캐릭터에서 PoB를 만들어 씁니다.
- 지원 링크: pobb.in, poe.ninja/pob, maxroll.gg/poe/pob, poedb.tw/pob.
- 빌드 가이드 링크도 읽습니다. maxroll의 PoE1 빌드 가이드(maxroll.gg/poe/build-guides), poe-vault, mobalytics 가이드 링크를 주면 그 안의 PoB를 찾아 씁니다. 가이드를 이름으로 찾아 달라고 하려면 웹 검색 키(Tavily)가 있어야 합니다. 체험 코드에는 웹 검색이 없습니다. "maxroll에서 사이클론 쇼크웨이브 슬레이어 가이드 찾아서 '맥스롤 사이클론'으로 등록해줘"처럼 maxroll은 사이트 안에서 바로 찾아 등록합니다. 빌드를 사이트 자체 플래너에만 두는 가이드(모바리틱스 일부 등)는 가이드의 "Export to PoB" 버튼에서 나온 코드나 링크를 붙여 주세요.
- 설정 > 게임 > 빌드 계산 엔진에서 "PoB 계산 엔진 사용"을 켜면 처음 한 번 PoB 소스와 LuaJIT를 내려받습니다(약 250MB, 십여 초). 그다음부터 "이 벨트로 바꾸면 어때", "이 젬 대신 저거 쓰면", "이 노드 찍으면" 같은 질문에 DPS와 생존력 변화를 수치로 답합니다. 비교할 아이템은 게임에서 복사(Ctrl+C)한 뒤 물어보세요.
- 심연 영원의 주얼이 꽂힌 빌드는 엔진이 못 불러와 요약 비교로 답합니다.
- 앱 안 브라우저로 거래소에 로그인해 두면 "내 빌드", "내 장비", "내 캐릭터"라고 물을 때 지금 캐릭터의 장비와 패시브를 직접 읽습니다. PoB 링크를 등록해 두면 그쪽이 우선입니다. 계정 이름을 못 찾으면 설정 > 게임 > 거래소의 계정 이름 칸(Name#1234)에 넣어 주세요.
- "내 저항 몇이야?" 같은 수치 질문은 PoB 계산값으로 답합니다. 저항은 화염, 냉기, 번개, 카오스 네 가지를 다 말하고, 상한을 넘긴 만큼(초과 저항)도 같이 알려 줍니다.

### 참고 빌드 여러 개 등록하기

따라가고 싶은 빌드를 이름을 붙여 여러 개 등록해 두고, 이름으로 불러 비교합니다.

- 대화로 등록: "이거 '게이머비누 정전기'로 참고 빌드 등록해줘 (링크)"
- 설정으로 등록: 설정 > 게임 > 내 캐릭터 > 참고 빌드 칸에 한 줄에 하나씩 "이름 | 링크"로 적고 저장합니다. 대화로 등록한 빌드는 그 칸 아래에 따로 보이고, 칸을 저장해도 지워지지 않습니다.
- 비교: "게이머비누 정전기랑 내 빌드 비교해 줘"처럼 이름으로 부릅니다.
- 패시브: "참고 빌드랑 패시브 뭐가 달라?", "다음에 뭐 찍어?"처럼 물으면 찍은 노드 차이와 다음에 찍을 노드를 알려 줍니다.
- 가정 계산: "X랑 Y 같이 찍으면 어때?"처럼 여러 변화를 한꺼번에 넣어 PoB로 계산합니다.

### 유튜버의 PoB 찾아 등록하기

"4Easy 정전기 타격 캠페인 PoB 찾아서 '포이지 캠페인'으로 등록해줘"처럼 말하면 유튜브에서 영상을 찾고, 영상 설명에 있는 PoB 링크를 참고 빌드로 등록합니다. 유튜브 검색에는 따로 키가 필요 없습니다. 별명으로 부르면 못 찾을 수 있으니 채널 이름을 같이 말해 주세요. 예를 들어 "포이지"는 채널 이름 "4Easy"로 찾아야 잘 나옵니다.
- 패시브와 스킬 젬은 카카오 한글 이름으로 말하고 알아듣습니다. 이름 없는 작은 노드만 영어로 나올 수 있습니다.

## 6. 캐릭터 모델 고르기

설정 > 캐릭터 > 아바타에서 모드를 고릅니다.

- 기본은 2.5D 캐릭터 히요리(Live2D 무료 샘플)입니다. 처음 켜면 기어 마스코트가 보이고, 피드의 "같이 시작하기" 첫 줄 "2.5D 캐릭터 켜기"에서 Live2D 약관에 한 번 동의하면 Cubism Core를 받아 히요리로 바뀝니다. 설정에서는 "기본 제공: 히요리 사용"으로 되돌립니다.
- 기어: 기본 마스코트입니다. 모델을 불러오지 못하면 이 모습으로 돌아옵니다.
- VRM(.vrm): 기본으로 Seed-san이 들어 있습니다. 내 파일을 쓰려면 경로 칸에서 .vrm 파일을 고릅니다.
- Live2D(.model3.json 또는 .zip): Live2D Cubism Core는 앱에 들어 있지 않습니다. "Live2D 지원 활성화"를 누르고 동의하면 공식 주소에서 PC로 내려받습니다. zip을 고르면 앱이 풀어서 .model3.json을 찾습니다.

캐릭터 외형에서 크기(120에서 400픽셀)와 평소 투명도를 정합니다. 바를 움직이면 바로 보이고, 저장해야 유지됩니다. 모델에 표정이나 모션이 있으면 캐릭터 탭 아래쪽 "고급 설정"을 펼친 뒤 "감정 매핑"에서 감정별로 직접 지정할 수 있고, 비워 두면 이름을 보고 추측합니다. VRM 파일 크기 제한은 코드에서 찾지 못했습니다. 너무 무거우면 느려질 수 있습니다.

### 모델을 구하는 곳과 넣는 법 (2026-11-13 화면 기준)

**VRoid Hub (hub.vroid.com)**: 3D VRM 모델이 가장 많습니다. 받으려면 pixiv 계정으로 로그인해야 합니다.
1. 목록 페이지에서 "Filter by conditions of use"를 열고 "Third-party use: Allow", "Download: Allow", "Avatar use: Allow"에 체크한 뒤 Apply. 주소로 바로 가려면 hub.vroid.com/en/models?is_downloadable=1&characterization_allowed_user=everyone 입니다.
2. 모델 페이지의 "Can you use this model?"이 Yes인지, 그 아래 "Conditions of use" 줄을 읽습니다. 항목은 Avatar Use(아바타 사용), Violent acts(폭력 표현), Sexual acts(성적 표현), Corporate use(법인 이용), Individual commercial use(개인 상업 이용), Redistribution(재배포), Alterations(개변), Attribution(출처 표기)입니다. 아바타 사용이 Allow면 이 앱에 써도 됩니다. 방송이나 영상에 올릴 생각이면 개인 상업 이용도 보세요. Attribution: Required면 제작자를 적어 주세요.
3. "Use this model"을 누르면 pixiv ID 로그인을 거쳐 .vrm 파일을 받습니다(형식 VRM 0.0 또는 1.0, 둘 다 됩니다).
4. 앱에서 설정 > 캐릭터 > 아바타 > 모드를 "VRM 아바타"로 바꾸고, 경로 칸 옆 찾기 버튼으로 받은 .vrm을 고른 뒤 저장. 캐릭터 창에 바로 그려지고, 안 되면 기본 마스코트로 돌아옵니다.

**BOOTH (booth.pm)**: 무료 VRM도 있습니다. booth.pm/en/search/VRM?max_price=0 으로 가면 0 JPY 항목만 보이고 상품 페이지에 "Free Download" 버튼이 있습니다. 받으려면 pixiv 계정이 필요하고 받은 파일은 구매 내역(Purchase History)에 남습니다. 주의: VRM 검색에 VRChat 전용 아바타(unitypackage)가 많이 섞여 있습니다. 파일 목록에 .vrm이 있는 것만 이 앱에 씁니다. 상점마다 이용 규약이 다르니 상품 페이지 아래를 읽으세요.

**VRoid Studio**: 내 모델을 직접 만들어 .vrm으로 내보냅니다. 기본 프리셋은 상업 이용 가능으로 안내되지만, 특별 표시가 붙은 소재는 그 조건을 따르세요.

**Live2D 공식 샘플 (live2d.com/en/learn/sample)**: 로그인 없이 받습니다. 히요리, 하루, 시즈쿠, 마크, 즌다몬 등 20여 종이고 모델마다 Download 버튼이 있습니다. 받기 전에 "Free Material License Agreement"와 "Live2D Cubism Sample Data Terms of Use"를 읽어야 하고, 하츠네 미쿠와 유니티짱은 별도 가이드라인을 따릅니다. 받은 zip 안의 runtime 폴더에 .model3.json이 있습니다.
1. 앱에서 설정 > 캐릭터 > Live2D 지원 > "Live2D 지원 활성화"를 누르고 동의 창에서 "동의하고 다운로드"를 누릅니다. Cubism Core는 Live2D사 소프트웨어라 앱에 없고 이때 공식 주소에서 받습니다.
2. 모드를 Live2D로 바꾸고 모델 칸에서 .model3.json이나 받은 zip을 고릅니다. zip은 앱이 풀어서 .model3.json을 찾습니다.

실제로 해 본 것(2026-11-13, 윈도우 11): 공개 샘플 .vrm을 경로 칸에 넣고 저장하면 캐릭터 창에 그려지고, 기본 Seed-san으로 되돌려도 그려집니다. 크기와 투명도를 바꿔 저장하면 재시작 뒤에도 유지됩니다. 지금 판(0.1.10)에서는 VRM 크기 변경이 재시작 뒤에 반영되는 문제가 있어 다음 판에서 고칩니다.

남의 모델을 다시 올리거나 고쳐서 나눠 주는 일은 허용 표시가 없으면 하지 마세요.

## 7. 성격과 말투 쓰기

설정 > 캐릭터에서 프로필을 고르거나 새로 만듭니다. 이름과 말투는 바로 보이고, 성격과 말투, 예시 대사, 피할 것, 첫인사는 "이름과 성격" 아래 "고급 설정"을 펼치면 나옵니다. 칸은 이렇습니다.

- 이름
- 성격과 말투: 자유롭게 씁니다. 사실 규칙보다 우선하지는 않습니다. 최대 2,000자.
- 말투: 자동(성격 설명에서 읽음), 반말, 존댓말 중 하나.
- 예시 대사: 상황(20자 이내)과 대사(120자 이내)를 한 줄씩. 최대 12줄. 숫자는 넣지 마세요. 모델이 예시 숫자를 사실처럼 따라 말할 수 있습니다.
- 피할 것: 최대 6개, 각 30자 이내, 쉼표로 나눕니다.
- 첫인사: 한 줄에 하나, 최대 8개, 각 300자 이내.

카드 전체(설명, 예시 대사, 피할 것)는 모델에게 2,000자까지만 전달됩니다. 길면 예시 대사가 뒤에서부터 빠지고 8줄은 남습니다. 모델은 형용사보다 실제 대사 몇 줄을 훨씬 잘 따라 합니다.

다른 곳에서 만든 캐릭터 카드(Character Card V2/V3의 PNG, JSON)를 "카드 불러오기"로 가져올 수도 있습니다. 새 프로필로 추가되고 지금 프로필은 그대로입니다. 카드의 지시문, 상황 설정, 로어북은 보관만 하고 적용하지 않습니다. 2,000자를 넘으면 잘립니다. 내보내기는 JSON으로 합니다.

캐릭터 카드로 가져오는 순서:
1. 카드는 성격 설명, 첫인사, 예시 대사가 들어 있는 PNG(그림 안에 데이터가 숨어 있음)나 JSON 파일입니다. SillyTavern 같은 프로그램에서 "Export character"로 내보낸 파일이 이 형식이고, 카드를 나누는 커뮤니티에서 받은 파일도 같습니다. 성인물이 많은 곳이 있으니 필터를 켜고 고르세요.
2. 설정 > 캐릭터 탭 아래쪽 "고급 설정"을 펼치고 캐릭터 카드 > "카드 불러오기 (PNG, JSON)"를 누른 뒤 파일을 고릅니다.
3. "새 프로필로 추가했어요: 이름 (형식)" 줄과 썸네일이 뜨고, 그 프로필이 바로 활성 프로필이 됩니다. 재시작해도 남습니다.
4. 영어 카드면 성격과 첫인사가 영어 그대로 들어옵니다. 동반자는 한국어로 답하지만 첫인사는 원문대로 나오니 필요하면 첫인사 칸을 고쳐 저장하세요. 2,000자를 넘는 설명은 잘립니다.

실제로 해 본 것(2026-11-13, 윈도우 11): 공개 예시 카드(Seraphina, V3 PNG)를 불러오자 새 프로필과 첫인사 1개, 썸네일이 들어왔고 다음 응답부터 그 이름으로 말했습니다.

### 예시 1: 차분한 베테랑 (반말)

성격과 말투 칸에 넣을 글:

```
수많은 리그를 겪은 베테랑 엑자일. 말수가 적고 차분하다.
위기에는 짧게, 먼저 말한다. 잘한 건 담담하게 인정한다.
모르는 건 모른다고 하고 확인하자고 한다.
반말, 한두 문장으로 끝낸다. 설교하지 않는다.
```

예시 대사 (상황 / 대사):

- 사망 / 쓰러졌네. 장비부터 보고 다시 들어가자.
- 위기 / 체력 낮아. 일단 빠져.
- 보스 처치 / 잡았다. 깔끔했어.
- 시세 못 구함 / 그 가격은 아직 못 봤어. 지어내진 않을게.
- 레벨업 / 올랐네. 찍을 패시브 있으면 같이 보자.
- 오래 조용할 때 / 조용하네. 쉬는 거면 쉬어, 필요하면 불러.

피할 것: 스포일러, 확인 안 한 시세 말하기, 긴 설명, 이모지

### 예시 2: 거래에 밝은 쾌활한 친구 (반말)

```
거래소와 시세를 좋아하는 활발한 친구. 득템에는 같이 신나 한다.
말은 빠르고 밝지만 숫자는 정확해야 한다고 생각한다.
확인하지 못한 가격은 모른다고 솔직하게 말한다.
반말, 감탄사를 자주 쓰되 한 번에 두 문장 안쪽으로 말한다.
실패하면 먼저 달래고, 그다음에 방법을 말한다.
```

- 희귀 드랍 / 와 이거 좋아 보인다! 시세부터 같이 보자.
- 사망 / 으악 괜찮아 괜찮아, 이런 날도 있지!
- 귓속말 거래 / 귓속말 왔다! 손님이야, 확인해 봐.
- 시세 못 구함 / 아 가격을 못 건졌어. 대충 찍어서 말하긴 싫어.
- 거래 질문 / 급하면 조금 낮춰서 파는 것도 방법이야. 어느 쪽이 편해?
- 보스 처치 / 잡았다아! 방금 완전 멋있었어!
- 오래 조용할 때 / 어이, 살아 있지? 너무 조용해서 심심하다!

피할 것: 스포일러, 확인 안 한 시세 말하기, 긴 설명, 이모지

### 예시 3: 건조하고 빈정대는 전략가 (존댓말)

```
계산이 빠르고 건조한 전략가. 농담도 표정 없이 한다.
빈정거리지만 선을 넘지 않고, 도움이 되는 말은 반드시 덧붙인다.
존댓말을 쓰되 거리감 있게, 한두 문장으로 말한다.
감정 표현은 적고 판단은 분명하다. 모르면 모른다고 한다.
```

- 사망 / 예상 가능한 결과였습니다. 저항부터 확인하시죠.
- 위기 / 체력이 바닥입니다. 계속 서 계실 이유가 없습니다.
- 희귀 드랍 / 쓸 만해 보입니다. 팔기 전에 시세는 확인하세요.
- 시세 못 구함 / 그 가격은 확인하지 못했습니다. 모르는 숫자는 말하지 않습니다.
- 빌드 질문 / 장비부터 보시죠. 저항이 비면 딜은 그다음입니다.
- 보스 처치 / 처치했습니다. 나쁘지 않았습니다.
- 잡담 / 저는 여기 있습니다. 용건이 있으면 말씀하세요.

피할 것: 스포일러, 확인 안 한 시세 말하기, 긴 설명, 이모지

세 예시 모두 카드 본문이 2,000자보다 훨씬 짧고, 예시 대사는 12줄 이하이며, 상황은 20자, 대사는 120자 이내이고, 피할 것은 4개에 각 30자 이내입니다.

### 말투 고르는 기준

- 반말은 친구 같고, 존댓말은 거리가 있어 빈정거림에도 어울립니다.
- 자동으로 두면 성격 설명의 말투를 읽습니다. 헷갈리면 직접 고르세요.
- 피할 것은 짧은 금지어가 긴 설명보다 잘 지켜집니다.

## 8. 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 오버레이가 안 보임 | 게임을 창 모드나 테두리 없는 창 모드로 바꾸세요. |
| 동료가 게임에 반응 안 함 | 설정 > 게임 > 로그 경로가 맞는지 보세요. 카카오는 logs 폴더의 KakaoClient.txt 또는 Client.txt 중 최근에 바뀐 파일입니다. 앱을 관리자 권한으로 켰는지도 확인하세요. |
| 대답이 없음 | 위쪽 버튼이 "시작하기"로 보이면 눌러서 켜세요. 두뇌 프리셋과 키를 확인하고 연결 테스트를 누르세요. 402는 결제나 크레딧 문제, 키 거부는 키 오류입니다. 무료 한도를 다 썼을 수도 있습니다. |
| 대답이 1분쯤에서 이유를 말하고 멈춤 | 조회가 오래 걸려 끊은 것입니다. 잠시 뒤 다시 묻거나 질문을 좁혀 보세요. |
| 거래소가 "로그인 안 됨"으로 바뀜 | 거래소 로그인이 풀렸습니다. 설정 > 게임 > 거래소에서 다시 로그인하세요. |
| 목소리가 안 나옴 | 키가 없으면 edge-local 음성으로 바뀝니다. 그래도 안 나오면 음소거를 확인하고 음성 연결 테스트를 해 보세요. |
| 말이 자꾸 틀리게 들림 | 조용한 곳에서 해 보고, 정확 모드(240MB)를 쓰세요. 그래도 답답하면 OpenAI 음성 인식으로 바꾸세요. |
| 단축키가 안 먹음 | 다른 프로그램이 같은 조합을 쓰고 있을 수 있습니다. 시스템 탭에서 다른 조합으로 바꾸세요. 감정 단축키는 게임 창이 앞에 있을 때만 동작하는 옵션도 확인하세요. |
| 새 리그가 목록에 없음 | 리그 목록을 새로 고치거나 이름을 직접 입력하세요. |
| 시세를 못 구함 | 잠시 뒤 다시 물어보세요. 거래소가 느릴 수 있습니다. |

### 버그 신고

표로 해결되지 않으면 설정 > 시스템 > 버그 신고를 써 주세요.

1. "무엇을 하다가 무슨 일이 생겼나요?" 칸에 상황을 적고 "신고 내용 만들기"를 누릅니다. 앱 버전, 설정 상태 요약, 적은 내용이 만들어집니다.
2. 내용을 확인하고 복사해서 디스코드 버그-제보 채널에 붙여 넣습니다. 길면 여러 번에 나눠 복사합니다. 앱이 스스로 보내는 것은 없습니다.
3. "로그 파일 열기 (첨부용)"로 로그 파일을 열어 같이 첨부해 주세요. 어디서 막혔는지 바로 보여 고치기가 훨씬 빨라집니다. 로그에는 API 키, 체험 코드, 거래소 쿠키가 기록되지 않습니다.

디스코드가 어렵다면 help@vibestash.app 로 메일을 보내도 됩니다. 디스코드 서버 "PoE Companion"(https://discord.gg/cTN8FhmCjs)과 사용 안내는 설정 > 시스템 > 커뮤니티와 문의에서도 열 수 있습니다.

로그 파일: `%APPDATA%\@game-companion\desktop-poe1\logs\companion.log`
데이터 폴더: `사용자 폴더\.companion\poe1\` (PoE2 데이터와 따로 둡니다)

## 9. 개인정보 요약

API 키는 내 PC의 설정 파일에만 있고 우리에게 아무것도 보내지 않습니다. 거래소 로그인 쿠키도 이 PC에 암호화해 두고, 버그 신고는 내가 직접 복사해 붙여 넣을 때만 나갑니다. 앱이 스스로 접속하는 곳은 새 버전을 확인하는 GitHub뿐입니다. 귓속말과 채팅 줄, 질문은 내가 고른 대화 모델 회사로 갑니다. 무료 등급은 입력을 학습에 쓸 수 있습니다. 자세한 내용은 소개서를 보세요.
